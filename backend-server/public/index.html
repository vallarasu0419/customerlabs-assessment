🎯 Action Recorder Widget Test Page About

Test the embeddable event tracking configuration widget

📋 How to Test:

  1. First, build the widget by running: npm install && npm run build
  2. The widget is controlled by URL query parameters:
To SHOW the widget: /index.html?cl_widget=define To HIDE the widget: /index.html?cl_widget=track
  1. Once you visit with /index.html?cl_widget=define, the widget will persist across page reloads
  2. To remove it, visit with /index.html?cl_widget=track
  3. Try the widget features:
    • Move: Click the move button (arrows icon), then drag the widget
    • Minimize: Click the minimize button (horizontal line icon)
    • Search: Use the search box to filter events
    • Pagination: Navigate through pages (3 items per page)
    • Close: Click the X button to close and set tracking mode

Demo Website Content

This is a sample webpage to test the Action Recorder Widget. The widget should overlay on top of this content without interfering with the page's functionality.

  • Button and link clicks
  • Form submissions
